# Contributing

Contributions are welcome through GitHub issues and pull requests.

Before submitting a change:

1. Do not include real screenshots, device identifiers, IP addresses, domains,
   credentials, logs, databases, or locally built binaries.
2. Run `python server/test_config_sync.py`.
3. Keep changes focused and document any configuration or security impact.
4. Confirm that the code is used only with informed consent on authorized
   devices.

By contributing, you agree that your contribution is licensed under the MIT
License included in this repository.
